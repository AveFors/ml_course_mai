# Wine Quality

Исходные файлы UCI, без изменений:

- `winequality-red.csv` — красное вино;
- `winequality-white.csv` — белое вино;
- `winequality.names` — описание и библиографическая ссылка авторов.

Источник: https://archive.ics.uci.edu/dataset/186/wine+quality

Архив: https://archive.ics.uci.edu/static/public/186/wine%2Bquality.zip

Получены 13 октября 2026 года. Разделитель CSV — точка с запятой.

Цитирование: Cortez, P., Cerdeira, A., Almeida, F., Matos, T., & Reis, J. (2009).
Wine Quality [Dataset]. UCI Machine Learning Repository.
https://doi.org/10.24432/C56S3T
